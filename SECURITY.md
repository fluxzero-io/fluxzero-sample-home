# Security Policy

## Scope

This policy covers the Fluxzero Home sample application. It is an executable
example, not a production-supported home automation system. Reports should
identify the affected version or commit; applications derived from this example
need their own maintenance and security assessment.

The [Fluxzero security policy](https://github.com/fluxzero-io/.github/blob/main/SECURITY.md)
describes the shared maintenance and coordinated disclosure process.

## Reporting a vulnerability

Use this repository's **Security > Report a vulnerability** action when available.
Otherwise report privately through the
[Fluxzero security reporting channel](https://github.com/fluxzero-io/.github/security/advisories/new).
Do not open a public issue or pull request for an undisclosed vulnerability.

Include the affected version or commit, platform, expected impact, and a minimal
reproduction. Remove credentials, production secrets, customer data, and private
household or Home Assistant information from examples and logs. Maintainers
coordinate triage, remediation, and disclosure privately with the reporter.
